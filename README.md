# Programación Java

Repositorio dedicado al aprendizaje y práctica de programación utilizando Java.

Aquí documento mi progreso mediante ejercicios, retos y proyectos desarrollados durante mi formación como estudiante de Ingeniería de Software, fortaleciendo fundamentos de programación, pensamiento lógico y Programación Orientada a Objetos.

## Objetivos

- Dominar los fundamentos de Java.
- Desarrollar habilidades de resolución de problemas.
- Aplicar buenas prácticas de programación.
- Construir una base sólida para el desarrollo backend.
- Prepararme para tecnologías como SQL, Spring Boot y APIs REST.

## 🛠 Tecnologías

- Java
- IntelliJ IDEA Community Edition
- Git
- GitHub

## Contenido

- Fundamentos de Java
